This project was done to learn C fundamentals and thus **may be unsafe**.

<h2>**Functioning**</h2>

When running organizer.exe you may provide an argument that provides the absolute path to the directory you want to organize.
After doing this, it will move files to new sub-directories that are appropriate to their extensions (.jpg and .png files will move to a folder called Images/, .pdf will move to Documents/ etc.)
